# SARAVANAN — THE SERIES

A cinematic, streaming-inspired portfolio for **Saravanan R**, Automation Engineer. Built from his resume. Every section is an episode, every project is an Original.

## Run it
Needs Node.js 18+.
```
npm install
npm run dev
```
Build: `npm run build` (output in `dist/`, deploy to Vercel / Netlify / GitHub Pages).

## Change content
Everything is in `src/data/portfolio.ts`. Resume PDF: replace `public/assets/Saravanan_R_Resume.pdf`.

## Your photo
Replace `pic1.jpeg` (photo) and `pic.png` (same photo, background removed, same size), then run `npm run images`.
